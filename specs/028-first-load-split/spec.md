# Feature Specification: 첫 화면 JS 줄이기

**Feature Branch**: `028-first-load-split`
**Created**: 2026-10-08
**Status**: Implemented (v1.16.1)
**근거**: 민서 요청 "모든 기능을 최적화 해서 구현해줘"(2026-10-07). 독자가 글 링크로 처음 들어올 때 글쓰기·설정·관리자 화면 코드까지 받고 있었다.

## User Scenarios & Testing

### User Story 1 - 글을 읽으러 온 사람은 읽는 데 필요한 코드만 받는다 (Priority: P1)
1. **Given** 처음 온 독자, **When** 글·블로그·홈·태그·검색 주소로 들어오면, **Then** 첫 JS 묶음에 글쓰기·설정·가입·관리자·탈퇴 화면 코드가 들어 있지 않다.
2. **Given** 그 독자가 [글쓰기]·[설정] 같은 화면으로 옮기면, **Then** 그 화면 코드를 그때 받고, 받는 동안 "불러오는 중…"이 보인다.

## Requirements
- **FR-001**: 읽기 화면(홈, 글, 블로그, 시리즈, 팔로우 목록, 태그, 검색, 피드, 좋아한 글, 알림, 로그인)은 첫 묶음에 둔다.
- **FR-002**: 나머지 화면(글쓰기, 글 관리, 설정, 탈퇴·복구, 가입·비밀번호·메일 인증, 약관·동의, 관리자)은 처음 열 때 받는다.
- **FR-003**: 서버 응답·주소·화면 동작은 바뀌지 않는다.

## Success Criteria
- **SC-001**: 첫 JS(`index-*.js`)가 432KB(gzip 128KB)에서 305KB(gzip 94KB)로 준다.
