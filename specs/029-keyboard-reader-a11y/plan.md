# 구현 메모: 029 키보드·화면 읽기 프로그램 이동 개선 (v1.16.2)

## 구조
| 파일 | 역할 |
|---|---|
| `lib/focusMain.ts` | 본문 자리(`#main-content`, 없으면 첫 `main`)에 초점. 화면 이동은 스크롤 없이, 건너뛰기는 그 자리까지 스크롤 |
| `components/SkipLink.tsx` | "본문으로 건너뛰기". 본문 자리로 초점과 스크롤을 옮기고 주소에 `#`을 남기지 않는다 |
| `App.tsx` | 머리말 앞에 `SkipLink`. 모든 화면을 `<div id="main-content" tabIndex={-1}>` 안에 그린다 |
| `lib/router.tsx` `Link` | 이동 → 맨 위로 스크롤 → 다음 그림에서 `focusMain()` |
| `styles.css` | `.skip-link`(초점 때만 보임), 본문 자리·`main` 초점 테두리 없음 |

## 결정
- 초점 이동은 `Link`를 눌렀을 때만 한다. `navigate(..., { replace })`로 주소만 바꾸는 곳(글쓰기 첫 저장, 로그인 돌려보내기)에서 쓰던 칸의 초점을 빼앗지 않으려는 것이다.
- 화면마다 `main`이 따로 있지만 따로 불러오는 화면은 먼저 "불러오는 중" 표시를 그린다. `main`에 초점을 주면 실제 화면으로 바뀔 때 그 `main`이 사라지며 초점도 사라진다. 그래서 경로와 불러오기 상태가 바뀌어도 남는 감싸개(`#main-content`)에 초점을 준다.
- 기능이 늘지 않은 접근성 개선이라 Patch 버전이다.
