# Feature Specification: 본문 사진 자리 먼저 잡기

**Feature Branch**: `032-image-dimensions`
**Created**: 2026-10-08
**Status**: Implemented (v1.16.5)
**근거**: 민서 요청 "모든 기능을 최적화 해서 구현해줘"(2026-10-07). 본문 사진은 `loading="lazy"`로 늦게 받는데 크기 정보가 없어, 사진이 도착할 때마다 아래 글이 밀려 내려갔다(읽던 줄을 놓친다). 올릴 때 이미 가로·세로를 저장하고 있었지만 HTML에 쓰지 않았다.

## User Scenarios & Testing

### User Story 1 - 사진이 늦게 와도 읽던 자리가 그대로다 (Priority: P1)
1. **Given** 사진이 여러 장 든 글, **When** 독자가 스크롤하며 읽는 동안 사진이 하나씩 도착하면, **Then** 사진 자리는 처음부터 비어 있고 글이 밀리지 않는다.
2. **Given** 좁은 화면이나 아주 긴 사진, **When** 사진이 화면 폭이나 높이 제한(80vh)보다 크면, **Then** 비율을 지킨 채 줄어들고 찌그러지지 않는다.

## Requirements
- **FR-001**: 작성자가 올린 사진 중 가로·세로를 아는 사진의 `<img>`에 `width`, `height`를 적는다.
- **FR-002**: 크기를 모르는 사진, 남의 사진(링크로 바뀜), GIF 첫 장면(썸네일)에는 적지 않는다.
- **FR-003**: 정화 규칙은 `img`의 `width`, `height`로 1~99999의 숫자만 허용한다.
- **FR-004**: 렌더링 버전을 3으로 올려 이미 쓴 글도 다음에 읽을 때 새 규칙으로 다시 그린다.

## Success Criteria
- **SC-001**: 사진이 든 글에서 사진이 도착할 때 생기는 레이아웃 이동(CLS)이 0이 된다.
