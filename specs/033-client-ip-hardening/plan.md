# 구현 메모: 033 사용자 IP 판정 다지기 (v1.16.6)

| 파일 | 바뀜 |
|---|---|
| `shared/web/ClientIpResolver` | IPv4 정규식을 0~255로, 접두사 범위 검사, 테스트용 `List<String>` 생성자(스프링은 `BlogProperties` 생성자) |
| `ClientIpResolverTest` (새로) | 헤더 무시, 오른쪽부터 판정, 헤더 없음, IPv6, `/22` 경계, 숫자 아님, 잘못된 설정 7개 |

## 결정
- 앞자리 0(`01.2.3.4`)도 숫자 주소로 보지 않는다. 접속 주소와 로드 밸런서가 붙이는 주소에는 나오지 않는 표기다.
- 신뢰 대역 안에서 `unknown` 같은 숫자 아닌 홉이 오면 지금처럼 그 값을 사용자 주소로 쓴다(요청 제한 키로만 쓰인다).
- 버그 수정이라 Patch 버전이다.
