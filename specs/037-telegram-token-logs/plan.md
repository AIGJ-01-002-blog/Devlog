# 구현 메모: 037 잘못 들어간 텔레그램 토큰이 로그에 남지 않게 (v1.16.10)

| 파일 | 바뀜 |
|---|---|
| `telegram/infra/HttpTelegramApi` | 주소 만들기를 `try` 안으로 옮겼다. 조회 두 개는 `get(method, query, timeout)` 하나로 모았고, 보내기는 `RuntimeException`도 종류만 남기고 `FAILED` |
| `HttpTelegramApiTest` (새로) 9개 | 가짜 Bot API 서버로 확인: 봇 이름 한 번만 묻기·실패 뒤 다시 묻기, 토큰 없으면 호출 없음, 업데이트 해석(글자 없는 메시지·대화 없음 포함), 실패 응답, 보내는 본문(서식 없음·미리보기 끔), `GONE`·`FAILED` 분류, 연결 안 됨, 잘못된 토큰 |

## 결정
- 토큰을 앞뒤 공백 정리해 살려 쓰지 않는다. 잘못된 설정은 꺼진 것처럼 실패하고, 운영자는 로그의 예외 종류로 알아챈다. 비밀값을 고쳐 쓰는 코드를 두지 않는다.
- 비밀값 노출 고침이라 Patch 버전이다.
- 잘못된 토큰 테스트는 고치기 전 코드에서 예외 메시지에 토큰이 든 채로 실패하는 것을 확인했다.
