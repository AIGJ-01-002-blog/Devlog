# Feature Specification: 글 공유 버튼

**Feature Branch**: `039-share-link`
**Created**: 2026-10-08
**Status**: Implemented (v1.17.0)
**근거**: 2026-10-07 밤샘 작업 지시(velog에 있는 기능 맞추기, 최적화). 민서 요청 "모든 기능을 최적화 해서 구현해줘". velog 글 상세에는 공유(링크 복사) 버튼이 있는데 여기에는 없었다.

## Requirements
- **FR-001**: 글 상세 아래 좋아요 옆에 [공유] 버튼을 둔다. 비공개 글에는 두지 않는다(작성자만 볼 수 있어 보낼 곳이 없다).
- **FR-002**: 휴대폰처럼 손가락으로 쓰는 기기는 기기의 공유 창을 연다. 데스크톱은 공유 창이 있어도 글의 전체 주소를 클립보드에 복사한다.
- **FR-003**: 결과를 버튼 옆에 3초 동안 보이고 화면 읽기 프로그램도 읽는다. 복사하면 "링크를 복사했어요", 복사할 수 없으면 주소창에서 직접 복사하라고 알린다. 공유 창을 닫으면 아무것도 하지 않는다.
- **FR-004**: 공유 창이 다른 이유로 실패하면 링크 복사로 넘어간다.

## 범위 밖
- 특정 SNS 버튼(트위터·페이스북 등)은 두지 않는다. 기기 공유 창과 링크 복사로 충분하다.
