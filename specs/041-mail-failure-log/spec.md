# Feature Specification: 메일 발송 실패 기록에서 받는 사람 주소 빼기

**Feature Branch**: `041-mail-failure-log`
**Created**: 2026-10-08
**Status**: Implemented (v1.18.1)
**근거**: 2026-10-07 밤샘 작업 지시(최적화·테스트). 민서 요청 "모든 기능을 최적화 해서 구현해줘". 테스트가 하나도 없던 `SmtpMailer`에 테스트를 붙이다가, 받는 사람을 가려 기록하려던 실패 로그에 SMTP 거절 응답 속 주소가 그대로 남는 것을 찾았다.

## Requirements
- **FR-001**: 메일 발송이 실패하면 받는 사람(가린 주소), 제목, 예외 종류만 기록한다. 예외 메시지는 기록하지 않는다(SMTP 응답 "550 5.1.1 <주소> User unknown"처럼 주소가 들어 있다).
- **FR-002**: 원인 예외가 있으면 맨 안쪽 원인의 종류도 함께 적어 실패 이유(인증·연결·주소)를 구분할 수 있게 한다.
- **FR-003**: 실패는 지금처럼 호출한 쪽(가입·인증 요청)으로 전해지지 않는다.

## 범위 밖
- 실패한 메일을 다시 보내는 기능은 없다(기존과 같음).
