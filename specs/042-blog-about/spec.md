# Feature Specification: 블로그 소개 탭

**Feature Branch**: `042-blog-about`
**Created**: 2026-10-08
**Status**: Implemented (v1.19.0)
**근거**: 2026-10-07 밤샘 작업 지시(velog에 있는 기능 맞추기, 최적화). 민서 요청 "모든 기능을 최적화 해서 구현해줘". velog 블로그에는 [글]·[시리즈]·[소개] 탭이 있는데 여기에는 [소개]가 없었다(한 줄 소개 bio만 있음).

## Requirements
- **FR-001**: 블로그에 [소개] 탭(`/@아이디/about`)을 둔다. 누구나 읽고, 마크다운을 글과 같은 규칙으로 그려 보인다(위험한 HTML 제거, 코드 강조, 본인이 올린 사진만).
- **FR-002**: 본인은 그 자리에서 [소개 쓰기]/[소개 수정]으로 마크다운을 고친다. 앞뒤 공백을 빼고 10,000자까지. 넘으면 저장 버튼이 꺼지고 서버도 400(ABOUT_TOO_LONG)으로 거절한다. 너무 복잡한 원문은 글과 같이 400.
- **FR-003**: 비워서 저장하면 소개를 지운다. 소개가 없으면 남에게는 "소개가 없어요.", 본인에게는 쓰기 버튼을 보인다.
- **FR-004**: 원문은 본인에게만 내려준다. 응답은 공유 캐시에 넣지 않는다.
- **FR-005**: 서버가 그린 소개 페이지는 소개가 있을 때만 검색 엔진이 수집한다. 탈퇴한 회원·없는 주소는 404.
- **FR-006**: 탈퇴 정리(30일 뒤) 때 소개를 지운다.
- **FR-007**: 소개에만 쓴 사진은 쓰지 않는 사진 정리(009 FR-041)에서 지우지 않는다.

## 범위 밖
- 소개 신고, 소개 안 사진 올리기 버튼(글에서 올린 사진 주소를 붙여 넣어 쓴다), 미리보기.
