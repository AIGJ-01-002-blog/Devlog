# Feature Specification: 블로그 소셜 정보

**Feature Branch**: `043-social-links`
**Created**: 2026-10-08
**Status**: Implemented (v1.20.0)
**근거**: 2026-10-07 밤샘 작업 지시(velog에 있는 기능 맞추기, 최적화). velog 프로필에는 이메일·GitHub·X(트위터)·Facebook·홈페이지 소셜 정보가 블로그 머리에 링크로 보이는데 여기에는 없었다.

## Requirements
- **FR-001**: 설정에 [소셜 정보]를 두고 이메일·GitHub·X·Facebook·홈페이지 다섯 칸을 한 번에 저장한다. 빈 칸은 지운다.
- **FR-002**: GitHub·X·Facebook은 아이디나 프로필 주소(`https://github.com/아이디` 등, 앞의 `@`도)를 받아 아이디만 저장한다. 다른 사이트 주소는 받지 않는다. 아이디 형식은 각 서비스 규칙을 따른다(GitHub 영숫자·하이픈 39자, X 영숫자·밑줄 15자, Facebook 영숫자·점 5~50자).
- **FR-003**: 이메일은 가입과 같은 규칙(공백 제거·소문자·형식)으로 정리한다. 홈페이지는 http(s) 주소만 받고(스킴이 없으면 https), 계정 정보가 든 주소와 공백·제어 문자는 받지 않는다. 254자까지.
- **FR-004**: 틀린 칸이 하나라도 있으면 아무것도 바꾸지 않고 틀린 칸을 모두 알려 준다(400, 칸별 코드 `SOCIAL_<종류>_INVALID`).
- **FR-005**: 블로그 머리(누구나)에 값이 있는 것만 정해진 순서로 링크를 보인다. 링크는 `rel="me nofollow noopener noreferrer"`.
- **FR-006**: 탈퇴 정리(30일 뒤) 때 지운다.

## 범위 밖
- 아이콘 이미지(글자 링크로 보인다), 다른 서비스(LinkedIn 등), 글 상세 작성자 카드에 보이기.
