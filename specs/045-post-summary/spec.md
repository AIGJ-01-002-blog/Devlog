# Feature Specification: 글 짧은 소개

**Feature Branch**: `045-post-summary`
**Created**: 2026-10-08
**Status**: Implemented (v1.22.0)
**근거**: 2026-10-07 밤샘 작업 지시(velog에 있는 기능 맞추기). velog는 발행 화면에서 목록에 보일 "짧은 소개"(150자)를 직접 쓴다. 지금은 본문 앞부분으로만 요약했다.

## Requirements
- **FR-001**: 발행 설정 창에 "짧은 소개" 칸을 둔다. 다시 발행할 때는 지금 소개로 미리 채운다.
- **FR-002**: 소개는 줄바꿈·연속 공백을 한 칸으로 줄이고 앞뒤 공백을 지운다. 150자(코드 포인트)까지 쓸 수 있다. 넘으면 `SUMMARY_TOO_LONG`으로 다른 발행 오류와 함께 알려주고 발행하지 않는다.
- **FR-003**: 소개를 쓴 글은 목록 카드·RSS·공유 설명(meta description)·글 상세 응답의 `excerpt`에 소개를 그대로 쓴다.
- **FR-004**: 소개를 비우면 저장하지 않고(NULL) 지금처럼 본문 앞부분으로 요약한다.
- **FR-005**: 소개는 발행할 때 확정된다. 발행한 글을 고치는 중(작업본)에는 독자에게 이전 소개가 보인다.

## 범위 밖
- 대표 사진(썸네일) 직접 고르기.
- 검색 결과 문장(검색어 주변 본문을 보인다, 014).
