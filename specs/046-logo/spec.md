# Feature Specification: 새 로고 (파비콘·헤더)

**Feature Branch**: `046-logo`
**Created**: 2026-10-08
**Status**: Implemented (v1.22.1)
**근거**: 2026-10-08 민서님이 프로젝트 로고(펼친 책 + `</>`)를 정해 보냄("로고는 이거 써"). 앱의 파비콘과 헤더 로고를 이 그림으로 바꾸고, 다크 모드에서도 보이게 한다. README는 다른 스레드가 맡는다.

## Requirements
- **FR-001**: 브라우저 탭 아이콘(`/favicon.svg`)을 새 로고로 바꾼다. 기기가 다크 모드면 밝은 색으로 그린다.
- **FR-002**: 헤더의 "devlog" 글자 앞에 로고 그림을 둔다. 그림은 글자와 같은 색이라 사이트 테마(밝게·어둡게·기기 설정)를 따른다. 화면 읽기 프로그램에는 글자만 읽힌다.
- **FR-003**: 홈 화면에 추가할 때 쓰는 `/apple-touch-icon.png`(180px, 흰 바탕)를 둔다.

## 범위 밖
- 공유 기본 그림(`og-default.png`), README.
