# Feature Specification: 글 썸네일 고르기

**Feature Branch**: `047-post-thumbnail`
**Created**: 2026-10-08
**Status**: Implemented (v1.23.0)
**근거**: 2026-10-07 밤샘 작업 지시(velog에 있는 기능 맞추기). velog는 발행 화면에서 썸네일을 직접 올리거나 없앤다. 지금은 본문 첫 사진만 썸네일이 됐다(045 범위 밖으로 남긴 항목).

## Requirements
- **FR-001**: 발행 설정 창에 "썸네일" 칸을 둔다. 미리보기와 [사진 올리기]·[본문 첫 사진으로]·[썸네일 없애기]가 있다. 다시 발행할 때는 지금 고른 상태로 미리 채운다.
- **FR-002**: 고르지 않으면 지금처럼 본문 첫 사진이 썸네일이다.
- **FR-003**: 직접 올린 사진은 본문 사진과 같은 규칙(형식·크기·하루 장수·저장 공간)으로 올라간다. 고를 수 있는 사진은 작성자가 여기에 올린 사진뿐이고, 남의 사진이나 바깥 주소는 `THUMBNAIL_INVALID`로 거부한다.
- **FR-004**: [썸네일 없애기]를 고르면 본문에 사진이 있어도 목록 카드에 사진이 없고, 공유 미리보기는 사이트 기본 그림을 쓴다. 고르기와 없애기를 같이 보내면 `THUMBNAIL_CONFLICT`.
- **FR-005**: 고른 썸네일은 목록 카드(홈·블로그·피드·검색·시리즈)·글 상세 응답·공유 미리보기(og:image)에 함께 쓴다.
- **FR-006**: 고른 사진은 본문에 없어도 사진 정리에서 지워지지 않는다. 다른 사진으로 바꾸거나 고르기를 풀면 연결 해제 시각을 남겨 7일 뒤 정리한다. 글을 완전히 지울 때도 같다.
- **FR-007**: 썸네일은 발행할 때 확정된다. 발행한 글을 고치는 중에는 독자에게 이전 썸네일이 보인다.

## 범위 밖
- 본문 사진 중 하나를 골라 썸네일로 쓰기(지금은 첫 사진 또는 새로 올린 사진).
- 썸네일 자르기(카드가 16:9로 가운데를 보여 준다).
