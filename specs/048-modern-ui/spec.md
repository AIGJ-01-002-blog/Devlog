# Feature Specification: 모던 개발 블로그 화면

**Feature Branch**: `048-modern-ui`
**Created**: 2026-10-08
**Status**: Implemented (v1.24.0)
**근거**: 2026-10-08 민서님 요청("velog처럼 할 필요 없고 트렌디한 블로그 느낌으로, 형식을 바꿔도 된다"). 방향 문서: [docs/60](https://github.com/AIGJ-01-002-blog/docs/blob/main/design/60-direction-ai-mcp-premium.md)

## 사용자 시나리오

1. **Given** 처음 온 비회원, **When** 홈을 열면, **Then** 서비스 소개(한 줄 문구, 설명, [글쓰기 시작하기]·[태그 둘러보기])가 글 목록 위에 보인다. 로그인한 사람에게는 보이지 않는다.
2. **Given** 썸네일이 없는 글, **When** 목록 카드를 보면, **Then** 회색 빈칸 대신 글마다 정해진 그라데이션 위에 제목 첫 글자와 `devlog/@주소`가 올라간 표지가 보인다. 같은 글은 언제 봐도 같은 색이다.
3. **Given** 어떤 화면이든, **When** 아래로 스크롤하면, **Then** 헤더가 반투명하게 내용 위에 떠 있고 아래 구분선이 보인다.

## Requirements

- **FR-001**: 강조색을 velog 초록에서 인디고로 바꾼다. 글자 `--color-brand` 라이트 `#4f46e5`(흰 배경 6.3:1) / 다크 `#a5b4fc`, 흰 글자가 올라가는 버튼 `--color-brand-fill` `#4f46e5`(6.3:1).
- **FR-002**: 회색 계열을 zinc 톤으로 바꾼다. 페이지 배경 `#FFFFFF` / `#121212`(021 FR-014·FR-015)와 토큰 이름은 그대로 두고 값만 바꾼다(docs/45 §3 "개인 서비스는 값만 바꾼다"). 흐린 글자는 배경·보조 배경 위 4.5:1 이상(theme.test).
- **FR-003**: 모서리를 키운다(`--radius` 8px, 카드·대화상자·코드 블록 `--radius-lg` 14px). 카드는 큰 그림자 대신 얇은 테두리, 마우스를 올리거나 키보드 초점이 들어오면 4px 뜨고 썸네일이 4% 커진다.
- **FR-004**: 썸네일 없는 카드 표지(시나리오 2). 색은 `id mod 4`로 정하고, 표지는 장식이라 화면 읽기 프로그램에 읽히지 않는다(카드 썸네일 링크가 이미 `aria-hidden`). 서버가 그린 첫 화면처럼 표지 안이 비어 있으면 예전처럼 "devlog" 글자를 보인다.
- **FR-005**: 비회원 홈 소개(시나리오 1). 로그인 상태를 읽는 동안에는 그리지 않는다. 소개 문구는 소제목 태그를 쓰지 않아 화면의 제목 구조(h1 하나)가 그대로다.
- **FR-006**: 홈의 [최신]·[트렌딩] 탭을 알약 모양으로 바꾼다. 다른 탭은 밑줄을 강조색으로 바꾼다.
- **FR-007**: 글 본문을 개발 문서처럼 다듬는다. 제목 굵게·자간 좁게, 줄 간격 1.8, 코드 블록 테두리, 인라인 코드 테두리, 인용 둥근 모서리, 링크 밑줄 간격, 본문 사진 둥근 모서리, 작성자 카드는 상자로.
- **FR-008**: 움직임 줄이기를 켠 사람에게는 카드 뜨기와 썸네일 커지기를 하지 않는다(031).
- **FR-009**: 375px·320px 화면에서 가로로 넘치지 않는다.

## 범위 밖
- 웹 글꼴 내려받기(Pretendard·JetBrains Mono는 기기에 있으면 쓰고, 없으면 지금 글꼴). CSP와 첫 화면 크기 때문에 번들에 넣지 않는다.
- 카드에 태그·읽는 시간 표시(목록 API에 없음).
- 에디터 화면 배치 변경.
