# Feature Specification: MCP 개발 일지 중심 첫 화면

**Feature Branch**: `050-mcp-devlog-home`
**Created**: 2026-10-08
**Status**: Implemented (v1.26.0)
**근거**: 2026-10-08 민서님 답(6번): "슬로건을 crowfoot처럼 MCP 개발 일지 기능을 메인으로, UI도 그에 맞게". 5번: MCP를 모든 회원에게 열고 "MCP로 사용자의 AI에 연결하면 개발 일지를 자동으로 작성"을 핵심 기능으로.

## 사용자 시나리오

1. **Given** 처음 온 비회원, **When** 홈을 열면, **Then** 슬로건 "코딩은 AI와, 기록은 devlog가."와 [AI에 devlog 연결하기]·[직접 글쓰기], 그리고 AI 도구에서 "개발 일지 써 줘"라고 하면 임시글이 생기는 예시 장면이 보인다.
2. **Given** 누구나, **When** 헤더의 [AI 연결] 또는 첫 화면 버튼을 누르면, **Then** `/mcp` 안내 화면에서 MCP가 무엇인지, 연결 3단계, Claude Code 명령·설정 파일(복사 버튼), AI가 쓸 수 있는 도구, 안전 장치를 읽는다.
3. **Given** 링크 미리보기·검색 엔진, **When** `/`나 `/mcp`를 읽으면, **Then** 설명에 슬로건이 들어 있다.

## Requirements

- **FR-001**: 슬로건은 "코딩은 AI와, 기록은 devlog가."다. 첫 화면 소개와 `/`·`/mcp`의 링크 미리보기 설명에 쓴다.
- **FR-002**: `/mcp`는 공개 화면이다(수집 허용). 연결 명령의 주소는 지금 사이트 주소 + `/api/mcp`, 토큰 자리는 `<내 토큰>`이다.
- **FR-003**: 안내 화면의 도구 목록에 바로 발행하는 도구는 없다. AI는 임시글과 "발행 대기"까지만 만들고, 사람이 화면에서 [발행]을 누른다.
- **FR-004**: MCP 서버와 토큰 발급이 열리기 전에는 안내 화면에 "곧 열려요"를 보인다(spec 051에서 없앤다).
- **FR-005**: 375px·320px에서 가로로 넘치지 않는다. 좁은 화면(640px 이하) 헤더에서는 [AI 연결]을 숨긴다.
- **FR-006**: 예시 장면은 장식이라 화면 읽기 프로그램에는 한 줄 설명만 읽힌다.

## 범위 밖
- MCP 서버 자체, 개인 접근 토큰 발급 화면(spec 051).
