# Feature Specification: 내 글 내보내기

**Feature Branch**: `056-post-export`
**Created**: 2026-10-08
**Status**: Implemented (v1.32.0)
**근거**: 058과 같은 요청. Crowfoot은 요구사항을 Markdown·CSV로 내보낸다. 블로그에서는 "내 글을 언제든 들고 나갈 수 있다"가 같은 가치이고, velog 사용자들이 자주 바라는 기능이다.

## 사용자 시나리오

1. **Given** 발행한 글 1개와 임시글 1개, 휴지통 글 1개, **When** 설정 › 내 글 내보내기를 열면, **Then** "내 글 2개를 …" 안내와 [⬇ Markdown으로 내보내기]가 보인다.
2. **Given** 같은 상태, **When** 버튼을 누르면, **Then** `devlog-{아이디}-{날짜}.zip`을 받고, 안에 `README.md`(글 목록), `posts/날짜-번호-제목.md`, `drafts/…md`가 있다. 휴지통 글은 없다.
3. **Given** 받은 파일, **When** 열면, **Then** 맨 위 YAML 머리말에 제목·날짜·수정일·상태·공개 범위·태그·시리즈·소개·주소가 있고 그 아래 Markdown 원문이 있다.
4. **Given** 10분 안에 5번 받은 회원, **When** 또 누르면, **Then** "10분에 5번까지" 안내가 뜨고 파일은 만들지 않는다.
5. **Given** 탈퇴 화면, **When** 글이 있으면, **Then** "먼저 내보내기에서 받아 두세요" 링크가 보인다.

## Requirements

- **FR-001**: `GET /api/me/export` → `{posts}`(휴지통에 없는 내 글 수). `GET /api/me/export.zip` → `application/zip` 첨부 파일, 스트리밍. 로그인 세션만(`/api/me/**`).
- **FR-002**: 발행한 글은 독자가 보는 발행본을, 임시글은 마지막으로 저장한 내용을 담는다. 고치는 중인 작업본은 담지 않는다.
- **FR-003**: 파일 이름은 `날짜-번호-제목.md`. 운영체제가 막는 글자와 `#`·`%`는 빼고 제목은 40자까지. 이름이 겹치면 `-2`를 붙인다.
- **FR-004**: 머리말 문자열은 큰따옴표로 감싸고 JSON과 같은 규칙으로 이스케이프한다(Hugo·Jekyll이 읽는 YAML).
- **FR-005**: 회원마다 10분에 5번까지(Redis 고정 창, 장애 때는 통과).
- **FR-006**: 사진은 블로그 주소 그대로 둔다(파일을 묶지 않는다).

## 범위 밖
- 사진·첨부파일까지 묶기, 다른 블로그에서 가져오기(import), 댓글 내보내기.
