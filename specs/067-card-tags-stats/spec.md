# 067 글 카드 태그·조회·댓글 수와 공개 설정 버튼 모양

요청: 민서님(2026-10-09) "공개설정 살짝 부자연스러워", "메인 페이지 카드형식에 태그도 보이도록, 조회수도, 댓글도 몇 개나 달렸는지. 99개 넘으면 99+ 이렇게 조회 모두, 태그는 3개까지 보여주고 이상이면 ... 처리"

## 동작
- 카드 API(`PostCard`, 홈·블로그·태그·피드·트렌딩·시리즈·검색 공용)에 `viewCount`와 `tags`(입력 순서, 전부)를 더한다. 태그는 같은 목록 쿼리 안의 `ARRAY(...)` 하위 쿼리로 읽어 목록당 쿼리 1번을 지킨다.
- 카드 본문: 요약 아래 태그 한 줄. 앞 3개만 `#태그` 링크로 보이고, 넘치면 `…` 칩 하나(툴팁에 나머지 태그). 태그가 없으면 줄이 없다.
- 카드 아래 줄 오른쪽: 조회 👁 · 댓글 💬 · 좋아요 ♥. 각각 99를 넘으면 `99+`, 툴팁·화면 낭독기에는 정확한 수("조회 12,950회").
- 글 화면 공개 설정: 기본 `select`는 그대로 쓰되(휴대폰 기본 선택 메뉴) 테두리·배경을 없애고 [수정]·[삭제]와 같은 글자 버튼 높이·굵기·마우스 올림 배경을 준다. 오른쪽에 작은 ▾ 아이콘. `field-sizing: content`로 고른 항목 폭만 차지한다.

## 고른 것과 이유
- **태그 전부를 내려보내고 화면에서 3개로 자른다**: 몇 개가 넘치는지와 나머지 이름을 툴팁으로 보여 줘야 해서다. 글당 태그는 많아야 수십 개라 응답이 크게 늘지 않는다.
- **조회·댓글·좋아요를 같은 규칙(99+)으로**: 민서님 말씀대로 "조회 모두". 좋아요도 같은 줄이라 맞췄다. 정확한 수는 글 화면과 툴팁에서 볼 수 있다.
- **사용자 정의 드롭다운 대신 모양만 바꾼 select**: 키보드·화면 낭독기·휴대폰 선택 휠이 그대로 동작하고 코드가 작다.
