# 068 UX/UI 다시 점검과 다듬기 (web-design-guidelines·frontend-design)

요청: 민서님(2026-10-09) "2개 추가해서 다시 ux/ui 설계랑 웹페이지 재검토해서 리팩토링 해줘"

새로 넣은 두 스킬을 기준으로 화면 전체를 다시 봤다.
- `web-design-guidelines`(Vercel Web Interface Guidelines): 접근성·초점·입력·터치·다크 모드 규칙. 페이지 39개, 컴포넌트, 공통 스타일을 셋으로 나눠 `파일:줄` 단위로 점검했다.
- `frontend-design`(Anthropic): 모든 카드가 뜨고 그림자가 생기는 효과, 제목 한 구절만 색을 바꾸는 강조 같은 "흔한 기본값"을 덜어 낸다.

한국어 화면이라 규칙 중 Title Case·둥근 따옴표·2인칭 문구는 적용하지 않았다.

## 바뀌는 것

### 공통 스타일 (styles.css·index.html·theme)
- **초점**: 입력칸(`.field` 안 input·select·textarea)과 모든 select에 3px 바깥 고리. 전에는 select에 초점 표시가 전혀 없었고 입력칸은 1px 테두리 색만 바뀌었다. 테두리 없는 에디터 제목 칸은 아래 선으로 초점을 보인다.
- **고정 머리말·아래 탭이 초점을 가리지 않게**: `html { scroll-padding-top: 80px }`, 휴대폰은 아래 탭 높이만큼 `scroll-padding-bottom`.
- **카드 효과 줄이기**: 카드가 4px 뜨고 그림자가 커지고 썸네일이 커지던 효과를 빼고, 마우스가 있는 기기에서만 테두리와 제목 색이 바뀐다. 휴대폰에서 누른 뒤 카드가 뜬 채로 남던 문제도 함께 없어진다. 내 글 관리의 통계·글 줄도 같다. 목차 현재 항목의 크기 키우기도 뺐다(글자가 떨려 보였다).
- **첫 화면 제목**: 한 구절만 보라색이던 강조를 없애 제목을 한 색으로.
- **휴대폰**: 입력칸 글자를 16px 이상으로(아이폰이 초점 때 화면을 확대하지 않게), 댓글 버튼·태그 지우기·탭·좋아요·필터 칩 등 누르는 곳을 36~40px로. 두 번 눌러 확대 지연을 없애는 `touch-action: manipulation`, 탭 강조색 정리, 눌렀을 때 버튼이 살짝 어두워지는 피드백.
- **노치**: `viewport-fit=cover`를 넣어 아래 탭의 `safe-area-inset`이 실제로 동작하고, 가로 모드 좌우 여백도 챙긴다.
- **주소창 색**: `theme-color`를 라이트(#ffffff)·다크(#121212)로 넣고, 테마를 직접 고르면 그 색으로 바꾼다.
- **긴 글자**: 페이지 제목·블로그 이름·창 제목·소개글·시리즈 편집 줄에서 끊김 없는 긴 단어가 화면 밖으로 나가지 않게. 검색 탭 줄이 좁은 화면에서 줄어들게.
- **창·목록 스크롤**: 창·메뉴·알림·목차·백업·수정 이력·미리보기에서 끝까지 스크롤해도 뒤 화면이 같이 움직이지 않게(`overscroll-behavior: contain`).
- 제목에 `text-wrap: balance`, 빈 썸네일의 "devlog" 글자 대비 올리기.

### 화면 (페이지·컴포넌트)
- **실패를 성공처럼 보이던 곳 바로잡기**: 내 글 관리에서 목록을 못 불러오면 "글이 없어요" 대신 오류와 [다시 시도]. 글 화면·내 글 관리 알림에서 오류가 초록(성공) 띠로 보이던 것을 경고 띠로.
- **되돌릴 수 없는 일 앞에서 한 번 묻기**: 백업 지우기, 첨부 빼기, AI 제안 넘기기, 작성 중인 소개 취소, 텔레그램 연결 끊기, 관리자 권한 바꾸기.
- **오류·상태를 화면 낭독기에 알리기**: 불러오기 실패·입력 오류·자동 저장 상태·가입 화면의 아이디·주소·별명 확인 결과를 `role="alert"`/`aria-live`로, 입력칸과 오류 문구를 `aria-describedby`로 잇는다.
- **키보드**: 내 메뉴는 열면 첫 항목으로 초점이 가고 ↑↓·Home·End로 옮기며 Esc로 닫으면 버튼으로 돌아온다. 알림 창도 Esc·초점 이동을 챙긴다. 프로필 사진 자르기는 화살표 키로 위치를 옮길 수 있다.
- **창이 열린 동안 뒤 화면 스크롤 잠그기.**
- **휴대폰 키보드**: 검색 화면이 열리자마자 휴대폰 키보드가 튀어나오지 않게(마우스 기기에서만 자동 초점). 아이디·인증번호·SNS 아이디 칸은 자동 대문자·맞춤법을 끈다.
- 좋아요 버튼은 이름을 고정하고 눌림 상태(`aria-pressed`)로만 알린다. 장식용 이모지(🔒·👥·📎·⬇ 등)는 화면 낭독기가 읽지 않게. 날짜는 공용 형식(`lib/format`)으로 통일.

## 고른 것과 이유
- **카드 뜨기 효과를 없앤 것**: frontend-design이 "AI가 만든 티"로 꼽는 기본값이고, 휴대폰에서 눌린 채 떠 있는 버그가 있었다. 테두리·제목 색 변화만으로도 누를 수 있다는 신호는 충분하다.
- **되돌리기 창 대신 확인 창**: 되돌리기(undo)는 더 친절하지만 화면마다 상태를 새로 들고 있어야 한다. 이번에는 같은 동작을 모든 곳에 짧은 코드로 넣을 수 있는 확인 창을 골랐다.
- **누르는 곳 크기 36~40px**: PR 체크리스트의 "40px 안팎"을 따르되, 태그·필터 칩은 40px이면 줄이 너무 두꺼워져 36px로 했다.
- **브랜드 색·글꼴은 그대로**: 디자인 방향(048, 062)은 민서님이 이미 정했으므로 이번에는 바꾸지 않고, 규칙 위반과 흔한 장식만 걷어 냈다.
