# Feature Specification: 관리자 대시보드 지표 칸 다시 그리기

**Feature Branch**: `074-admin-kpi-board`
**Created**: 2026-10-09
**Status**: Implemented (v1.50.0)
**근거**: 블로그 주인이 대시보드 지표 11칸을 "보기 편하고 가시성 좋게" 다시 그려 달라고 요청했고, 초안(PR #124) 스크린샷을 보고 "좋아 반영해줘"로 승인했다. 064(방문자), 066(활동한 회원), 070(검색 유입)의 지표를 다시 배치만 하고 집계는 바꾸지 않는다.

## 사용자 시나리오

1. **Given** `/admin` 대시보드, **Then** 지표 11칸이 세 묶음으로 나뉜다.
   - **방문**: 방문자, 방문, 오늘, 검색 유입 (넓은 줄 전체)
   - **회원·글**: 활동한 회원, 가입, 새 글
   - **반응**: 조회, 댓글, 좋아요, 신고
2. **Then** 각 칸은 이름, 큰 숫자(단위는 작게), 이전 기간 대비 증감(▲·▼와 비율), "이전 N", 날짜별 흐름 막대(마지막 날은 진하게)를 보인다.
3. **Then** 증감 색은 좋아진 쪽이 초록, 나빠진 쪽이 빨강이다. 신고는 늘면 나쁨으로 본다. 변화가 없으면 회색이다.
4. **Then** '오늘' 칸은 기간과 상관없이 오늘 방문자이고, 아래에 어제 값을 보인다.
5. **When** 칸을 누르면, **Then** 아래 날짜별 그래프가 그 지표로 바뀐다(예전과 같다). 칸마다 `data-tip` 설명이 있다.
6. 휴대폰 화면에서는 묶음이 한 줄씩 쌓이고 칸은 두 줄로 놓인다. 라이트·다크 모드 모두 색 토큰만 쓴다.

## Requirements

- **FR-001**: 화면만 바꾼다. API·DB·집계는 그대로다.
- **FR-002**: 흐름 막대는 대시보드 응답의 `daily[]` 값을 그대로 쓰고, 값이 모두 0이면 바닥 선만 그린다.
- **FR-003**: 예전 `.stat-grid`·`.stat-tile`은 회원 화면(`AdminMemberPage`)이 계속 쓰므로 남긴다.
