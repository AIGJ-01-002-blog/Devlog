# Feature Specification: 팔로워·팔로잉 목록 공개 설정

**Feature Branch**: `079-follow-list-private`
**Created**: 2026-10-10
**Status**: Implemented (v1.56.0)
**근거**: 2026-10-10 블로그 주인 요청 "팔로워 팔로잉 목록을 내 메뉴 설정에서 공개 비공개 이렇게 껐다 켰다 할 수 있게 해주고 비공개 계정을 다른 계정이 보려고 하면 비공개 계정입니다 라고 표기되게 해줘".

## 사용자 시나리오

1. **Given** 로그인한 회원, **When** 내 메뉴 › 설정 › 계정의 [팔로워·팔로잉 목록: 다른 사람에게 공개]를 끄면, **Then** 바로 저장되고 "이제 다른 사람에게는 '비공개 계정입니다'로 보여요"라고 알려 준다. 다시 켜면 누구나 목록을 본다.
2. **Given** 목록을 비공개로 둔 회원 A, **When** 비회원이나 다른 회원(A를 팔로우하는 사람 포함)이 `/@A/followers`·`/@A/following`을 열면, **Then** 목록 대신 자물쇠와 "비공개 계정입니다"가 보인다. 탭의 팔로워·팔로잉 수는 그대로 보인다.
3. **Given** 같은 A, **When** A 본인이나 관리자·매니저가 열면, **Then** 지금처럼 목록이 보인다.

## Requirements

- **FR-001**: `member.follow_list_public`(기본 true, V29). `PATCH /api/me/settings`의 `followListPublic`로 바꾸고 `GET /api/me/settings`에 온다.
- **FR-002**: 비공개면 `GET /api/members/{handle}/followers|following`이 본인·관리자(ADMIN·MANAGER) 말고는 `{items: [], nextCursor: null, hidden: true}`를 준다. 404가 아니라 200이다(회원이 있다는 건 블로그에서 이미 보이므로).
- **FR-003**: 서버가 그리는 첫 화면(`/@{handle}/followers`)도 같은 규칙으로 목록을 빼고 "비공개 계정입니다"를 넣는다.
- **FR-004**: 팔로워·팔로잉 수(블로그 머리·목록 탭)는 공개 설정과 상관없이 그대로 보인다.
- **FR-005**: 비공개는 내 목록에만 건다. 내가 다른 사람의 공개 목록에 들어 있는 것은 그대로 보인다.

## 고른 것과 이유 (질문 없이 진행, 일일 보고에 기록)

- **수는 숨기지 않음**: 인스타그램·X의 비공개 계정도 수는 보여 준다. velog형 블로그에서 팔로워 수는 블로그를 처음 보는 사람이 읽는 신호이고, 요청도 "목록"을 가리는 것이었다.
- **한 스위치로 두 목록**: 요청이 "팔로워 팔로잉 목록을 공개 비공개"라서 팔로워·팔로잉을 함께 켜고 끈다. 따로 나누자는 요청이 오면 칸을 하나 더 둔다.
- **설정 › 계정 탭에 둠**: 같은 성격의 공개 설정(새 글 기본 공개 범위, 최근 활동 보이기)이 계정 탭에 있다. 내 메뉴의 [설정]에서 바로 간다.
- **본인·관리자는 봄**: 본인은 자기 목록을 관리해야 하고, 관리자는 신고 처리 때 관계를 봐야 한다.
- **글 공개 범위는 건드리지 않음**: 글은 이미 글마다 공개·친구·나만 보기가 있다.
