# Feature Specification: 휴대폰에서 글자가 칸 안에서 어색하게 줄바꿈되지 않게

**Feature Branch**: `082-mobile-wrap`
**Created**: 2026-10-10
**Status**: Implemented (v1.59.2, 다국어 보강 v1.61.1)
**근거**: 2026-10-10 블로그 주인 요청 "모바일 환경에서 일부 텍스트가 박스에 줄바꿈 되거나 하는 현상을 없앨 수 있어? 난 아이폰 15pro인데 다른 모든 기종에서 이런 현상을 점검 하고 해결 하고싶어" (아이폰 15 Pro 캡처: 내 블로그 탭이 "시리/즈", "소/개", "포트폴리오/로 보기"로 쪼개짐).

## 사용자 시나리오

1. **Given** 폭 320~430px 휴대폰, **When** 블로그(`/@handle`, 시리즈·소개 탭 포함)를 열면, **Then** [글 · 시리즈 · 소개 · 포트폴리오로 보기] 탭 글자가 한 줄로 보이고 낱말 중간에서 끊기지 않는다. 화면보다 넓으면 탭 줄만 옆으로 밀어 본다.
2. **Given** 같은 휴대폰, **When** 홈·글·소개·가입 화면을 보면, **Then** 한국어 문장은 낱말(어절) 단위로 줄이 바뀐다("좋/아요", "블로그예/요." 같은 끊김 없음).
3. **Given** 폭 320px 휴대폰이나 수정 이력·백업 버튼이 붙는 발행 글, **When** 글쓰기 화면을 열면, **Then** [발행]이 화면 밖으로 밀리지 않고 넘치면 오른쪽 정렬로 다음 줄에 내려온다.

## Requirements

- **FR-001**: 한국어 화면의 기본 줄바꿈을 낱말 단위로 한다(`body { word-break: keep-all; overflow-wrap: break-word }`). 일본어·중국어 화면은 081의 `word-break: normal` 규칙을 그대로 따른다.
- **FR-002**: 칸 최소 너비를 한 글자로 줄이는 `overflow-wrap: anywhere`를 기본값으로 쓰지 않는다(가로로 좁은 칸에서 글자가 세로로 쪼개지는 원인).
- **FR-003**: 블로그 탭은 글자를 접지 않고(`nowrap`), 640px 이하에서는 탭 줄 가로 스크롤, 380px 이하에서는 여백·글자 크기를 줄여 네 탭이 한 화면에 들어오게 한다.
- **FR-004**: 글쓰기 머리 버튼 줄은 넘치면 다음 줄로 내린다(오른쪽 정렬).
- **FR-005**: 사이트 맨 아래 링크, 가입 동의의 "(날짜 시행)", `@gi-…` 같은 블로그 주소는 줄 중간에서 끊지 않는다.

## 다국어 화면 보강 (v1.61.1)

**근거**: 2026-10-10 민서님 추가 질문 "다국어 지원에서도 … 이런 현상 모두 없는 거지??"

4. **Given** 화면 언어 English·日本語·中文, **When** 같은 7가지 폭에서 같은 화면을 보면, **Then** 제목·버튼·탭 글자가 낱자로 쪼개지거나 화면 밖으로 밀리지 않는다.

- **FR-006**: 일본어·중국어 화면에서도 회원이 쓴 글(제목·본문·요약·블로그 이름·소개·댓글)은 낱말 단위로 바꾼다. 대부분 한국어라 081의 `word-break: normal`을 따르면 "블로/그"처럼 끊긴다. 화면 문구(일본어·중국어)는 081 규칙을 그대로 따른다.
- **FR-007**: 글 아래 글쓴이 카드는 좁은 화면에서 [팔로우]를 다음 줄로 내린다(사진과 이름은 한 줄 유지)(일본어 `フォロー`가 320px에서 카드 밖으로 밀리던 것).
- **FR-008**: 로그인 화면 아래 링크(가입·비밀번호 찾기 등)는 한 덩어리로 줄을 바꾼다(일본어 "方", "録"만 다음 줄로 떨어지던 것).
- **FR-009**: 설정 › AI 연결의 토큰 만들기 칸은 고르기 칸이 긴 번역에 밀려 화면을 넘지 않는다(일본어 320px에서 4px 넘침). 일본어 권한 이름은 `書き込み + 読み取り` → `読み書き`로 줄여 칸 안에서 잘리지 않게 한다.
- **FR-010**: 알림 화면 제목은 버튼 줄에 밀려 "Notificati/ons"로 끊기지 않고, 버튼 줄이 아래로 내려간다.
- **FR-011**: 글 관리 첫 칸 일본어 이름을 `公開済みの記事` → `公開済み`로 줄인다(영어 Published, 중국어 已发布와 같은 길이, 3칸 줄에서 두 줄이 되던 것).

## 점검 방법

- 폭 320(갤럭시 폴드 앞화면·SE 1세대), 360(갤럭시 S), 375(아이폰 SE·mini), 390(아이폰 14), 393(아이폰 15 Pro), 412(픽셀), 430(Pro Max)에서 화면 43개(공개 25개는 운영 데이터, 로그인 18개는 로컬 서버)를 Playwright로 열고, 낱말이 두 줄에 걸치거나 짧은 버튼·탭 글자가 두 줄이 되거나 화면이 가로로 넘치는 곳을 셌다.
- 다국어(v1.61.1): `?lang` 대신 언어 저장값(`devlog.lang`)을 en·ja·zh로 바꿔 같은 화면 43개 × 7가지 폭 × 밝은·어두운 테마를 다시 봤다. 일본어·중국어는 글자 단위 줄바꿈이 정상이라 낱말 끊김 검사를 빼고, 넘침·버튼 두 줄만 셌다.
- 결과: 고치기 전 약 850건(공개 화면) → 고친 뒤 문단 속 가운뎃점·괄호에서 바뀌는 줄과 문장 안 링크의 자연스러운 줄바꿈만 남음.

## 고른 것과 이유 (질문 없이 진행, 일일 보고에 기록)

- **글자를 줄이기보다 낱말 단위 줄바꿈**: velog·네이버 블로그처럼 한국어는 어절 단위로 끊는 게 읽기 편하다. 사이트 전체에 한 번에 걸어 앞으로 생길 칸도 같이 막는다.
- **탭은 가로 스크롤 + 작은 화면에서 촘촘히**: 탭 이름을 줄이면("포트폴리오") 뜻이 흐려진다. 320px에서도 네 탭이 다 보이도록 여백만 줄였다.
- **[발행] 버튼은 다음 줄로**: 가장 중요한 버튼이 가려지면 안 되므로, 숨기거나 스크롤 대신 줄을 내린다.
